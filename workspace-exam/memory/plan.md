# Plan

> **계층 최상위.** Phase 단위의 목표·범위·종료 조건을 정의한다.
> 갱신 시점: (1) `/aidlc-plan` 최초 생성 (2) Hook cascade 3/3 — Phase 의 모든 Task 완료 시.
> Task 상세는 `tasks.md`, 학습 내용은 `long-term.md` 에 둔다. 여기에는 중복하지 않는다.

## 1. 전체 목표
- 제품 목표: AI-DLC 운영자가 진행 상황·Claude 사용량 확인과 루프 일시정지/재개를 로컬 브라우저 한 화면(Grafana 스타일)에서 끝내도록 하는 AI-DLC Monitor 를 만든다. 동시에 AI-DLC 프레임워크의 레퍼런스 예시 프로젝트가 된다.
- 성공 지표: KPI-01 (상태 파악 5초 이내), KPI-02 (다운로드 후 첫 화면 5분 이내, 실행 동작 1번)
