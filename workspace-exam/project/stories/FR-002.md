# FR-002 Plan·Task 진행률

## 1. 사용자 스토리
AI-DLC 운영자로서 Phase 별 진행률과 Task 목록을 보고 싶다, 남은 일을 알기 위해. (01 §5 원문)

- KPI: KPI-01 Q2 "지금 어떤 Task 를 어느 팀이 하나" 의 보조(현재 Task 행 강조). 주 답은 FR-003.
- API: `GET /api/v1/plan`, `GET /api/v1/tasks?team=&status=&phase=` (20 §5).

## 2. 규칙
- **Phase 집계** = Hook `Memory.phases()` 와 같은 결과: `## P<n>` 제목(`PHASE_RE`)부터 다음 `## ` 제목 전까지의 체크박스 줄(`CHECKBOX_RE`) 수가 전체, 그중 `[x]`/`[X]` 가 완료. `## Backlog`·`## Blocked` 등 Phase 가 아닌 섹션은 집계하지 않는다.
- **진행률** = `floor(완료 / 전체 × 100)` 정수 %. 전체 0 이면 진행률 0 + "Task 없음"(0 나눗셈 없음). 100% 는 전부 `[x]` 일 때만 보인다.
- **현재 Phase** = `plan.md` frontmatter `current_phase`. `completed_phases` 에 있는 Phase 는 "완료" 표시.
- **Task 줄 파싱** (형식 `- [ ] T-001 [team] 제목 — FR-001 | deps: T-000 | DoD: ...`): T-ID, 팀(`[...]` 첫 태그), 제목, FR, deps. 형식이 맞지 않는 체크박스 줄도 Phase 집계에는 포함하고(Hook 과 일치), 목록에는 원문 제목 + 팀 `-` + "형식 불일치" 표시로 보여 준다.
- **Task 상태** (우선순위 순서로 첫 번째 일치):
  1. `완료` (`done`): `[x]`
  2. `막힘` (`blocked`): T-ID 가 `## Blocked` 섹션의 항목 줄에 있음, 또는 STM `status: active`·`task` = 이 T-ID·`outcome: blocked`
  3. `진행 중` (`active`): STM `status: active` 이고 `task` = 이 T-ID
  4. `미착수` (`open`): 그 밖
- **필터**: 팀(목록에 있는 팀 id), 상태(위 4종), Phase. 조건은 AND.

## 3. 수용 기준 (Given/When/Then)
- **AC-1 (Phase 집계)** Given `## P1` 에 Task 5개(그중 `[x]` 3개), `## P2` 에 4개(`[x]` 0개)일 때 When `/plan` 을 조회하면 Then P1 = 3/5·60%, P2 = 0/4·0% 이고 같은 fixture 의 `Memory.phases()` 결과와 같다.
- **AC-2 (Hook 일치)** Given `full_workspace`·`workspace_100_tasks` 와 임의 변형 tasks.md 일 때 Then 모든 Phase 의 (전체, 완료)가 `Memory.phases()` 와 100% 같다.
- **AC-3 (내림)** Given P1 = 2/3 일 때 Then 진행률 표시는 `66%`. Given 99/100 일 때 Then `99%`.
- **AC-4 (Task 0개 Phase)** Given `## P3` 제목만 있고 체크박스가 없을 때 Then P3 = 0/0 + "Task 없음", HTTP 200.
- **AC-5 (비 Phase 섹션 제외)** Given `## Backlog` 에 체크박스 2개가 있을 때 Then 어느 Phase 에도 더해지지 않고 Task 목록에도 나오지 않는다.
- **AC-6 (목록 일치)** Given tasks.md 에 Task N개일 때 When 필터 없이 `/tasks` 를 조회하면 Then 목록의 T-ID·팀·제목·완료 여부가 tasks.md 원문 순서·내용과 같고 개수가 Phase 집계 전체 합과 같다.
- **AC-7 (진행 중)** Given STM `status: active`, `task: T-004`, `outcome: none` 일 때 Then T-004 의 상태 = `진행 중`, 목록에서 강조된다.
- **AC-8 (막힘)** Given `## Blocked` 섹션에 `- T-009 — blocker ...` 줄이 있을 때 Then T-009 = `막힘`. Given STM 이 T-004 active + `outcome: blocked` 일 때 Then T-004 = `막힘`.
- **AC-9 (우선순위)** Given T-002 가 `[x]` 이면서 `## Blocked` 에도 적혀 있을 때 Then T-002 = `완료`.
- **AC-10 (팀 필터)** Given 필터 `team=backend` 일 때 Then `[backend]` Task 만, 원문 순서로 나온다. Given 존재하지 않는 팀 id 일 때 Then 빈 목록 + "조건에 맞는 Task 없음", HTTP 200.
- **AC-11 (상태 필터)** Given `status=done` 일 때 Then `[x]` Task 만. Given `status=foo` 처럼 enum 밖 값일 때 Then HTTP 422 `VALIDATION_ERROR`, 본문 `{"error":{"code","message"}}`.
- **AC-12 (복합 필터)** Given `team=qa&status=open&phase=P1` 일 때 Then 세 조건을 모두 만족하는 Task 만 나온다(vitest 로 화면 필터 동작도 같은 결과).
- **AC-13 (형식 불일치 줄)** Given `## P1` 에 `- [ ] 아무 형식 없는 줄` 이 있을 때 Then P1 전체 수에 포함되고 목록에 "형식 불일치" 표시로 나온다.
- **AC-14 (깨진 tasks.md)** Given tasks.md 가 UTF-8 이 아니거나 frontmatter 가 깨졌을 때 Then Plan·Task 패널만 `meta.status = error`(`SOURCE_PARSE_ERROR`) + 안내 문구, 다른 패널 정상, HTTP 500 0건.
- **AC-15 (tasks.md 없음)** Given tasks.md 가 없을 때 Then `meta.status = empty` + "Task 목록이 없습니다 — `/aidlc-plan` 을 실행하세요".
- **AC-16 (plan.md 없음/깨짐)** Given plan.md 만 없거나 깨졌을 때 Then Phase 집계·Task 목록은 표시하고 현재 Phase·완료 Phase 표시는 `-`, `meta.status = partial` + 경고.
- **AC-17 (성능)** Given Task 100개일 때 Then `/plan`·`/tasks` 응답이 P-01 기준(첫 화면 ≤ 2초, 패널 p95 ≤ 200 ms) 안이다.
- **AC-18 (갱신 — P1 범위)** Given 대시보드가 열려 있고 tasks.md 가 바뀔 때 Then Task 목록은 `tasks` topic 수신 후 5초 이내 갱신된다(FR-008 P1 최소, sse-events §3). Phase 진행률 바의 자동 갱신(`plan` topic)은 **M2 필수**이며 P1 에서는 새로고침 시 반영되면 통과다. (P1 에서도 `tasks` topic 수신 시 `/plan` 을 함께 재조회하는 것을 권고 — 01 §5.1 흐름 3, STM §5 질문)

## 4. 예외·경계 흐름
| 상황 | 기대 동작 |
|------|-----------|
| 빈 workspace | AC-15 (empty) |
| 깨진 tasks.md / plan.md | AC-14 / AC-16 |
| STM 깨짐 | Task 목록은 표시, `진행 중`·STM 기반 `막힘` 판정 생략 + 경고(`partial`) |
| `[팀]` 태그 없음 | 팀 `-`, 팀 필터에서 어떤 팀에도 걸리지 않음 |
| 같은 T-ID 중복 | 원문 그대로 모두 표시(중복 제거하지 않음), 경고 1건 |

## 5. 화면 상태
| meta.status | 화면 |
|-------------|------|
| ok | Phase 별 진행률 바(완료/전체, %), 현재 Phase 강조, Task 표(T-ID·팀·제목·상태, 팀·상태·Phase 필터) |
| partial | ok + 경고 문구(무엇을 생략했는지) |
| empty | "Task 목록이 없습니다 — `/aidlc-plan` 을 실행하세요" |
| error | "Task 목록을 읽을 수 없음" + 오류 코드 |
| warming | 해당 없음 |
