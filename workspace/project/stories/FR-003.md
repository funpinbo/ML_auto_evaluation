# FR-003 메모리 상태

## 1. 사용자 스토리
AI-DLC 운영자로서 지금 STM 에서 어떤 Task 를 하고 있고 미처리 cascade 가 있는지 보고 싶다. (01 §5 원문)

- KPI: **KPI-01 Q2 "지금 어떤 Task 를 어느 팀이 하고 있나"** 의 주 답. 현재 Task·팀을 첫 화면 상단 행에 둔다. FR-005 일시정지가 Task 경계(미처리 cascade 0)에서 일어났는지 확인하는 근거.
- API: `GET /api/v1/memory` (20 §5).

## 2. 규칙
- STM: `short-term.md` frontmatter `status`(idle|active|closed), `task`, `team`, `opened_at`, `outcome`.
- **경과 시간** = 현재 시각 − `opened_at`. 표시 형식: 1분 미만 `1분 미만`, 그 외 `H시간 M분`(H = 0 이면 `M분`). 화면은 서버 재조회 없이도 최소 60초마다 경과 시간을 다시 그린다.
- LTM `rev`·`last_merged_stm`, tasks `synced_ltm_rev`, plan `completed_phases`.
- **미처리 cascade** = Hook `Memory(root).pending()` 의 `level` 만 사용(ADR-009 §1): 없음 / `ltm` → `1/3 LTM 갱신 필요` / `tasks` → `2/3 Task 갱신 필요` / `plan` → `3/3 Plan 갱신 필요`. Hook 메시지 문자열은 화면에 내보내지 않는다.
- **`aidlc.py status` 와의 일치**(01 원문): `status` 는 closed STM 을 아카이브하는 부작용이 있어 대시보드는 실행하지 않는다(D-07). 일치 검증은 qa 가 **복사본 workspace** 에서 `status` 를 실행해 비교한다(S-11). closed STM 은 `status` 가 먼저 아카이브하므로, 이 경우의 기준은 Hook 함수의 결론이다.

## 3. 수용 기준 (Given/When/Then)
- **AC-1 (active STM)** Given STM `status: active`, `task: T-004`, `team: product`, `opened_at: 2026-10-23T09:52:33+00:00` 이고 현재 시각이 `2026-10-23T11:15:33+00:00` 일 때 When `/memory` 를 조회하면 Then Task `T-004`, 팀 `product`, 시작 시각(로컬 시간대로 표시), 경과 `1시간 23분` 이 표시된다.
- **AC-2 (경과 경계)** Given 경과 59초 → `1분 미만`, 60초 → `1분`, 3600초 → `1시간 0분`.
- **AC-3 (idle STM)** Given STM `status: idle` 일 때 Then "진행 중인 Task 없음" 이 표시되고 Task·팀·경과는 `-` 다.
- **AC-4 (closed, 보관 전)** Given STM `status: closed` 이고 아직 아카이브되지 않았을 때 Then "STM 닫힘 — Hook 보관 대기" + Task·팀·outcome 이 표시되고, 조회 전후 `short-term.md`·`archive/` 가 바뀌지 않는다(해시 불변).
- **AC-5 (LTM·Task 동기)** Given LTM `rev: 5`, `last_merged_stm: 5`, tasks `synced_ltm_rev: 5` 일 때 Then 세 값이 그대로 표시되고 미처리 cascade = "없음".
- **AC-6 (cascade 1/3)** Given `archive/` 에 `last_merged_stm` 보다 큰 번호의 STM 아카이브가 있을 때 Then 미처리 cascade = `1/3 LTM 갱신 필요`.
- **AC-7 (cascade 2/3)** Given 아카이브 미반영 없음, LTM `rev: 6`, tasks `synced_ltm_rev: 5` 일 때 Then `2/3 Task 갱신 필요`.
- **AC-8 (cascade 3/3)** Given 1·2 해당 없음, `## P1` 이 전부 `[x]` 이고 plan `completed_phases` 에 P1 이 없을 때 Then `3/3 Plan 갱신 필요`.
- **AC-9 (가장 아래 단계 하나)** Given 1/3 과 2/3 조건이 동시에 있을 때 Then `1/3` 만 표시된다(Hook 은 가장 아래 계층 하나만 반환).
- **AC-10 (Hook 일치)** Given cascade 없음·1/3·2/3·3/3 fixture 각각에서 Then 대시보드 판정 == `Memory(root).pending().level`(없음 포함), 그리고 복사본에서 실행한 `aidlc.py status` 출력의 STM status/task/team, LTM rev·last_merged_stm, tasks synced_ltm_rev, "미처리 cascade" 값과 같다(closed STM fixture 는 §2 기준).
- **AC-11 (읽기 전용)** Given `closed_stm_workspace` 일 때 When `/memory` 를 반복 조회하고 SSE 를 연결해 두면 Then workspace 해시가 변하지 않고 Hook 쓰기 함수(`write_doc`, `reset_stm`, `archive_stm_if_closed`, `snapshot_stm`, `save_state`)가 한 번도 호출되지 않는다(ADR-009 §2).
- **AC-12 (opened_at 이상)** Given `opened_at` 이 없거나 RFC 3339 가 아니거나 미래 시각일 때 Then 경과 `-` + 경고 1건(`meta.status = partial`), Task·팀은 표시된다.
- **AC-13 (깨진 STM)** Given `short-term.md` frontmatter 가 미종결이거나 UTF-8 이 아닐 때 Then STM 영역만 "STM 을 읽을 수 없음"(`SOURCE_PARSE_ERROR`), LTM rev·cascade 판정은 가능한 범위에서 표시(`partial`), HTTP 500 0건.
- **AC-14 (LTM rev 숫자 아님)** Given LTM `rev: abc` 일 때 Then Hook `as_int` 와 같게 0 으로 해석하고 경고 1건을 붙인다(판정은 Hook 과 일치 유지).
- **AC-15 (자동 갱신 — FR-008 P1 최소)** Given 대시보드가 열려 있을 때 When `short-term.md`·`long-term.md`·`archive/` 가 바뀌면 Then 5초 이내 메모리 패널이 새 값으로 바뀐다(`memory` topic, 새로고침 없음). SSE 연결이 안 되면(503 `TOO_MANY_STREAMS` 등) 5초 폴링으로 같은 결과.
- **AC-16 (첫 화면)** Given 첫 화면을 열었을 때 Then 현재 Task ID 와 팀이 스크롤·클릭 없이 상단 행에 보인다(KPI-01 Q2, UAT).

## 4. 예외·경계 흐름
| 상황 | 기대 동작 |
|------|-----------|
| 빈 workspace (`workspace/memory/` 없음) | `meta.status = empty` + "메모리 파일이 없습니다 — `/aidlc-init` 을 실행하세요" |
| 일부 파일만 있음 (예: STM 만) | 있는 값 표시, 없는 값 `-`, cascade 판정은 Hook 과 같은 기본값(없는 파일 = 빈 frontmatter) |
| 깨진 파일 | AC-13·AC-14, 패널 단위 격리 |
| `memory_cascade.py` 로드 실패 | cascade 판정 `확인 불가` + "AI-DLC 엔진을 찾을 수 없음", STM·LTM 원값은 표시 |
| 루프 일시정지 중 | FR-005 와 함께 보면 STM `idle`, 미처리 cascade "없음" 이어야 정상(FR-005 AC 참조) |

## 5. 화면 상태
| meta.status | 화면 |
|-------------|------|
| ok | 현재 Task·팀·시작 시각·경과, LTM rev / last_merged_stm / synced_ltm_rev, 미처리 cascade 배지 |
| partial | ok + 생략 항목 경고 |
| empty | "메모리 파일이 없습니다 — `/aidlc-init` 을 실행하세요" |
| error | "메모리 상태를 읽을 수 없음" + 오류 코드 |
| warming | 해당 없음 |
