# FR-001. 멀티 모델-데이터 연결 (N:M)

## 사용자 스토리
사용자로서 내가 올린 여러 모델과 데이터를 UI 상에서 다대다로 자유롭게 이어붙이고 싶다, 왜냐하면 한 모델을 여러 데이터로, 혹은 여러 모델을 한 데이터로 평가해 보고 싶기 때문이다. (01§5 원문)

## 전제 (Precondition)
- FR-002(업로드)로 Model 1개 이상, Dataset 1개 이상이 이미 "평가 대상 목록"에 등록되어 있다.
- 본 스토리는 연결(Link) 생성/조회만 다룬다. 업로드 자체는 FR-002, 지표 선택은 FR-003, 실행은 FR-004 참고.

## 화면 흐름 (10§4 사용자 여정 2단계 — design 팀 부재로 product 가 직접 기술)
1. 업로드 화면(FR-002)에서 "연결" 화면으로 이동(또는 같은 화면 내 섹션)하면 등록된 Model 목록과 Dataset 목록이 각각 보인다.
2. 사용자가 Model 1개 + Dataset 1개를 선택하고 "연결" 동작(버튼/체크박스 매트릭스 등 구현 방식은 frontend 재량)을 수행하면 즉시 화면에 Link(조합) 1건이 추가되어 보인다.
3. 이미 등록된 Link 목록이 화면에 누적 표시되어, 다음 단계(FR-003 지표 선택, FR-004 Run)로 넘어갈 때 어떤 조합이 평가 대상인지 한눈에 확인할 수 있다.
4. 같은 Model 을 여러 Dataset 에, 같은 Dataset 을 여러 Model 에 반복해서 연결할 수 있어야 한다(N:M).

## API 계약 참조 (20§5, backend 소유 — product 는 계약을 수용 기준의 근거로만 인용)
- `POST /links` {model_id, dataset_id} → 201 {link_id} (또는 동등 응답)
- `GET /links` → 등록된 Link 목록

## 수용 기준 (Given/When/Then)

### AC-1 (기본 흐름 — 01§5 FR-001 원문 수용 기준)
Given Model A, Model B 가 업로드되어 있고 Dataset X 가 업로드되어 있는 상태,
When 사용자가 UI 에서 (Model A, Dataset X) 를 연결,
Then Link(Model A, Dataset X) 1건이 생성되어 Link 목록에 나타난다.

### AC-2 (N:M — 한 모델을 여러 데이터로)
Given Model A 가 이미 Dataset X 와 연결되어 있는 상태,
When 사용자가 (Model A, Dataset Y) 를 추가로 연결,
Then Model A 에 연결된 Dataset 이 X, Y 2개로 늘어나고 기존 Link(Model A, Dataset X)는 그대로 유지된다.

### AC-3 (N:M — 여러 모델을 한 데이터로)
Given Dataset X 가 이미 Model A 와 연결되어 있는 상태,
When 사용자가 (Model B, Dataset X) 를 추가로 연결,
Then Dataset X 에 연결된 Model 이 A, B 2개로 늘어나고, 두 Link 모두 FR-004 Run 대상 목록에서 조회된다.

### AC-4 (연결 목록 조회)
Given Link 가 2건 이상 생성된 상태,
When 사용자가 연결 화면(또는 해당 API)을 조회,
Then 생성된 모든 Link 가 (model_id, dataset_id) 쌍으로 빠짐없이 나열된다.

### AC-5 (예외 — 미업로드 대상 연결 시도)
Given 아직 업로드되지 않은(존재하지 않는) model_id 또는 dataset_id,
When 사용자가 해당 ID 로 연결을 시도,
Then 연결이 생성되지 않고 4xx 오류가 반환된다(FastAPI 기본 오류 포맷, user/02§6).

## MVP 성공 판단 기준과의 연결 (10§6)
"Given 모델 2개 + 데이터셋 1개 이상 업로드, When N:M 조합 생성..." 의 2번째 단계가 본 FR 이다. AC-2/AC-3 이 "모델 2개"를 N:M 으로 연결하는 시나리오를 그대로 검증한다.

## Out of scope (본 스토리에서 하지 않음)
- 연결 삭제/수정 UI (01§3·10§6 MVP 정의에 명시 없음 — 질문으로만 남김, 임의 추가하지 않음)
- 동일 (model, dataset) 조합의 중복 연결 허용 여부 — LTM I-02(30§2 유일성 주의) 미해결, 중복 연결 정책은 아직 결정되지 않았으므로 본 스토리의 수용 기준에서 다루지 않는다. **[architecture] Task 후보로 STM §5 에 기록.**
