# FR-004 테스트 케이스 — 평가 자동 실행 (Run)

> 대상 파일(예정): `tests/e2e/test_run_pipeline.py`(AC-1/2), `tests/integration/test_runs.py`(AC-3~5), 수동 체크리스트(AC-6).
