# FR-001 테스트 케이스 — 멀티 모델-데이터 연결 (N:M)

> fixture: `tests/fixtures/dummy_classifier.py`(predict 노출) 2개 모델 등록 가정(Model A, Model B) +
> `tests/fixtures/classification_data.csv` 1개 데이터셋 등록 가정(Dataset X). 대상 파일(예정): `tests/integration/test_links.py`.

| TC ID | 대응 AC | Given | When | Then (검증) | 레벨 | 상태 |
|-------|---------|-------|------|-------------|------|------|
| TC-001-01 | AC-1 | Model A, Dataset X 업로드됨(model_id, dataset_id 확보) | `POST /links {model_id: A, dataset_id: X}` | 201 + link_id 발급, `GET /links` 목록에 (A, X) 1건 존재 | integration | planned |
| TC-001-02 | AC-2 | Link(A, X) 이미 존재 | `POST /links {model_id: A, dataset_id: Y}` | 201, `GET /links` 에 (A,X)·(A,Y) 2건 모두 존재(기존 Link 유지 확인) | integration | planned |
| TC-001-03 | AC-3 | Link(A, X) 이미 존재 | `POST /links {model_id: B, dataset_id: X}` | 201, `GET /links` 에 (A,X)·(B,X) 2건 모두 존재, 둘 다 이후 Run 대상 조회(`GET /links`)에 나타남 | integration | planned |
| TC-001-04 | AC-4 | Link 2건 이상 생성됨(TC-001-02/03 선행) | `GET /links` | 응답 배열 길이와 각 원소의 (model_id, dataset_id) 쌍이 생성한 Link 와 1:1 일치, 누락 없음 | integration | planned |
| TC-001-05 | AC-5 | 존재하지 않는 model_id(예: 99999) | `POST /links {model_id: 99999, dataset_id: X}` | 4xx 응답, Link 레코드 생성 안 됨(`GET /links` 로 재확인) | integration | planned |
