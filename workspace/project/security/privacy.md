# 개인정보 체크리스트 — ML_miniops

> security 팀 소유(charter §3·§5 NFR-005). NFR-005 는 "이미 사용자 확인됨, 재검증 불필요"로 분류돼 있다(charter §5) —
> 이 문서는 그 전제가 이 Task 시점까지 깨지지 않았는지 재확인하고, 향후 변경 시 재확인할 체크리스트를 남긴다.

## 1. 결론 (요약)
**개인정보 없음 — 변경 없음 확인(이 Task 시점).** user/04-data-definition.md§6 의 "확인됨" 판단을 그대로 유지한다.

## 2. 재확인 내용

### 2.1 원본 근거 (사용자 확정)
- user/04-data-definition.md §6: "개인정보 포함 여부: 아니오 (확인됨 — 사용자가 올리는 모델/데이터에 개인정보 없음)", "처리 규칙: N/A (개인정보 미포함, 별도 마스킹/전송 제한 불필요)"
- user/04-data-definition.md §3 데이터 카탈로그(DS-01, 사용자 업로드 데이터): 민감도 "내부 (개인정보 없음 — 6번 확인됨)"

### 2.2 업로드 대상이 바뀌지 않았는지 확인 (20-architecture-analysis.md §4·§5 대조)
업로드로 시스템에 들어오는 데이터는 20§5 "주요 데이터 흐름" 기준 다음 2종뿐이다:
| 데이터 | 형식 | 흐름 | PII 가능성 |
|--------|------|------|------------|
| 모델 스크립트 | `.py` (`predict(X)->y` 계약, ADR-002) | Web UI → API → 모델 로더 → 로컬 파일 저장소 | 사용자 본인이 작성 — 사용자가 PII 를 코드에 하드코딩하지 않는다는 전제(사용자 책임, 03§8 로컬 신뢰 전제) |
| 데이터셋 CSV | CSV (마지막 컬럼=라벨) | Web UI → API → 로컬 파일 저장소 | 사용자가 PII 를 CSV 에 포함하지 않는다는 전제(04§6 확인됨) |

- 20-architecture-analysis.md §4/§5 에 사용자 계정정보, 외부 API 연동, 이메일/주소 등 PII 성격의 추가 데이터 소스는 등장하지 않는다 — **업로드 대상 변경 없음, 04§6 전제 유지됨**을 확인.
- 저장 위치: 로컬 파일 저장소(`workspace/data/`, 20§4) + SQLite 파일 — 외부 전송/제3자 공유 경로 없음(03§8, 06 데이터 정의서).

### 2.3 체크리스트
| 항목 | 상태 | 근거 |
|------|------|------|
| 업로드 CSV 에 PII 컬럼 포함 여부 | 아니오(사용자 확인 전제) | 04§6, DS-01 |
| 업로드 모델 스크립트에 PII 하드코딩 가능성 | 검사하지 않음 — 사용자 책임(로컬 신뢰 전제) | 03§8, threat-model.md §2 (R2) |
| 마스킹/익명화 처리 | 불필요 | 04§6 "처리 규칙 N/A" |
| 외부 전송/제3자 공유 | 없음 | 03§8, 20§6 |
| 보존기간/삭제 정책 | 명시 안 됨(사용자 문서에 규정 없음) | 04 문서 범위 밖 — 아래 §4 참고 |
| 비밀값/API 키 하드코딩 | 해당 없음(외부 API 키 자체가 없음) | 02§8 |

## 3. 변경 감지 트리거 (다음에 이 문서를 다시 열어야 하는 조건)
- 업로드 대상에 모델 스크립트/CSV 외의 데이터(예: 사용자 계정정보, 외부 API 연동, 다른 사람의 식별정보)가 추가되는 경우
- 04-data-definition.md §6 의 "확인됨" 전제가 사용자에 의해 변경되는 경우
- 공유/협업 기능(여러 사용자 간 데이터 공유) 등 NFR-004(동시 사용자 1명) 전제가 깨지는 아키텍처 변경이 발생하는 경우

## 4. 남은 일 / Task 후보
- 보존기간·삭제 정책이 어느 user 문서에도 명시돼 있지 않다. 1일 로컬 프로젝트 규모에서 과설계가 될 수 있어 신규 Task 로 올리지는 않되, 사용자가 명시적으로 요구하면 00-interpretation.md 질문으로 남길 사안이다(이번 Task 범위에서는 생성하지 않음 — PII 자체가 없어 실질 영향 낮음).
