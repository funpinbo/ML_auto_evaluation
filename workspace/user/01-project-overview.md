## 1. 배경 & 문제 정의
<!-- 왜 지금 이것을 만드는가? 해결하려는 고통은 무엇인가? 숫자가 있으면 숫자로. -->
- **문제:** AI-DLC 가 지금 몇 단계인지, 어떤 Task 를 하고 있는지, Claude 사용량이 얼마나 남았는지를 한눈에 볼 방법이 없다. 루프(`/aidlc-run N`)를 중간에 멈추려면 세션을 직접 끊어야 해서 진행 중인 Task 가 어중간한 상태로 남는다.
- **누가 겪는가:** VSCode 에서 Claude Code 로 AI-DLC 를 혼자 또는 소규모로 운영하는 개발자
- **현재 대안과 한계:** 터미널에서 `/aidlc-status` 를 실행하거나 `workspace/memory/*.md` 를 직접 열어 본다. 사용량은 Claude Code 의 `/usage` 를 따로 열어야 하고, 진행 상황과 사용량을 함께 볼 수 없다.
- **왜 지금인가:** AI-DLC 파이프라인과 Hook 이 완성되어 상태가 파일(frontmatter)로 표준화되었으므로 이를 읽어 시각화할 수 있다.

## 3. 범위
- **In scope (이번에 한다):** AI-DLC 파이프라인·Plan·Task·메모리·팀 상태 조회, Claude 사용량(한도 사용률·토큰·비용) 조회, 루프 일시정지/재개, 실행 로그 보기, 원클릭 실행 스크립트

### 5.1 주요 사용자 흐름
1. `run.bat`(Windows) 또는 `run.sh`(macOS/Linux) 실행 → 필요한 패키지 설치와 서버 실행 후 브라우저가 자동으로 열린다
2. 대시보드 첫 화면에서 파이프라인 단계, 현재 Task, 한도 사용률을 확인한다
3. VSCode 의 Claude Code 에서 `/aidlc-run 5` 실행 → 대시보드에서 진행률과 로그가 실시간으로 바뀐다
4. 사용량이 많으면 일시정지 → 현재 Task 가 끝나면 멈춤 → 나중에 재개

## 7. 제약 & 가정
- **기술 제약:** Frontend 는 Vue, Backend 는 Python + FastAPI + uvicorn. CI/CD 없이 사용자가 내려받아 실행하는 방식. 사용량은 VSCode 에 연결된 Claude Code 에서 가져온다.
- **예산/인력 제약:** 1인 개발
- **가정:** 사용자는 VSCode + Claude Code 확장(또는 CLI)과 Python 3.11 이상을 설치해 두었다. 요금제는 Claude 구독(Pro/Max) 기준이며, 한도 사용률은 Claude Code 가 제공하는 값을 그대로 쓴다.
