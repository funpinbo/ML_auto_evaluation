## 1. 배경 & 문제 정의
<!-- 왜 지금 이것을 만드는가? 해결하려는 고통은 무엇인가? 숫자가 있으면 숫자로. -->
- **문제:** 현재는 Jupyter Notebook 에서 모델을 하나씩 직접 로드해 평가한다. 그 결과 여러 모델의 평가 결과를 한눈에 비교하기 어렵고, 어떤 모델이 어떤 평가 결과를 냈는지 따로 수동으로 기록해야 한다.
- **누가 겪는가:** 모델을 직접 학습시키고 평가하는 사용자 본인 (1인 사용자 전제 — NFR-004 참고)
- **현재 대안과 한계:** 현재 대안은 Jupyter Notebook 수동 평가. 한계는 (1) 여러 모델/실행 결과를 한 화면에서 비교할 수 없음, (2) 평가 결과를 별도로 수동 기록해야 함.
- **왜 지금인가:** N/A (개인 생산성 도구, 외부 일정 압박 없음)

## 3. 범위
- **In scope (이번에 한다):** UI를 통해 사용자가 올린 모델과 데이터를 서로 연결(다대다)하고, 자동으로 평가를 실행해 결과를 시각화한다.
- **Out of scope (이번엔 안 한다):** 다중 사용자 동시 접속, 인증/권한 관리, 클라우드 배포, 분산/대규모 학습 파이프라인 (NFR-002~004, 7. 제약 과 일치)

| FR-001 | 멀티 모델-데이터 연결 | 사용자로서 내가 올린 여러 모델과 데이터를 UI 상에서 다대다로 자유롭게 이어붙이고 싶다, 왜냐하면 한 모델을 여러 데이터로, 혹은 여러 모델을 한 데이터로 평가해 보고 싶기 때문이다 | 사용자 | Must | Given 업로드된 모델과 데이터, When 사용자가 UI 에서 모델-데이터 쌍을 연결, Then 다대다로 여러 조합을 평가 대상으로 등록할 수 있다 |

| FR-004 | 평가 자동 실행 (Run) | 사용자로서 모델과 데이터를 연결한 뒤 Run 버튼만 누르면 자동으로 평가가 실행되길 원한다, 왜냐하면 평가 과정을 직접 코드로 돌릴 필요 없이 한 번에 처리하고 싶기 때문이다 | 사용자 | Must | Given UI 에서 연결된 모델-데이터 조합과 선택된 지표, When 사용자가 Run 버튼을 클릭, Then 시스템이 그 조합들을 하나의 실행(Run)으로 묶어 자동으로 평가하고 결과를 저장한다 |
| FR-005 | 결과 시각화 | 사용자로서 평가 결과를 그래프로 한눈에 비교하고 싶다, 왜냐하면 어떤 모델이 더 나은지 숫자보다 그래프로 보는 게 더 직관적이기 때문이다 | 사용자 | Must | Given 완료된 평가 결과(Evaluation), When 사용자가 결과 화면을 열면, Then 지표별 비교 그래프(예: 모델별 F1 막대 그래프)와 지표 간 상관관계 그래프를 pandas 기반으로 보여준다 |
