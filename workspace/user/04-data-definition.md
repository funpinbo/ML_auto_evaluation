## 2. 핵심 엔티티 & 관계
<!-- 예: User 1─N Conversation 1─N Message, FAQ N─M Category -->
- Model N─M Dataset (다대다 연결, FR-001). 사용자가 Run 버튼을 클릭하면 그 시점의 연결·지표 선택을 묶어 Run 레코드 1건이 생성되고(FR-004), Run 1─N Evaluation (Model·Dataset·Metric 조합별 결과, FR-003/005) N─1 Metric 이 생성된다.

### 2.1 주요 필드 (알고 있는 만큼)
| 엔티티 | 필드 | 타입 | 설명 | 비고 (PK/FK/개인정보) |
|--------|------|------|------|----------------------|
| Model | id, name, path, framework | str, str, path, enum(pytorch/sklearn) | 업로드된 모델 스크립트 식별 | PK: id |
| Dataset | id, name, path | str, str, path | 업로드된 CSV 데이터 식별 | PK: id |
| Run | id, created_at | str, timestamp | 사용자가 Run 버튼을 클릭한 1회 실행 단위 (KPI-02 집계 기준) | PK: id |
| Evaluation | id, run_id, model_id, dataset_id, metric, value | str, FK, FK, FK, enum(accuracy/f1/rmse), float | 평가 결과 1건 | FK: run_id→Run, model_id→Model, dataset_id→Dataset |
