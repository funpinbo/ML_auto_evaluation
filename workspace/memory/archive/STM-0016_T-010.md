- 패턴:
  - FastAPI 라우터 테스트는 `app.dependency_overrides[get_db]` 로 인메모리 SQLite 커넥션을 주입하고, 파일 저장 경로는 모듈 속성(`MODELS_DIR`)을 `monkeypatch.setattr` 로 `tmp_path` 로 교체해 실제 `workspace/data/` 를 건드리지 않는다 — 이후 datasets/links/runs 라우터 테스트도 동일 패턴 재사용 가능.
  - `model_loader.py` 처럼 "프레임워크 비의존 도메인 로직(예외만 올림) + 라우터가 HTTPException/로그로 변환" 분리는 engine.py/compatibility.py 등 다른 eval 모듈에도 동일하게 적용할 패턴.
- 이슈/리스크:
  - ruff(최신 버전 0.17.2) 기본 룰셋에 `flake8-bugbear` B008(`Depends()` 를 인자 기본값으로 쓰는 것)이 포함돼 FastAPI 표준 패턴을 오탐 — `pyproject.toml`/`ruff.toml` 이 없어 전역 설정으로 끄지 못하고 `# noqa: B008` 인라인 주석으로 해당 줄만 억제함. 이후 API 라우터를 추가하는 Task(T-011/T-013/T-015)도 `Depends(...)` 를 함수 인자 기본값에 쓸 때마다 같은 패턴(`# noqa: B008`)이 필요하거나, cicd/architecture 가 ruff 설정 파일을 신설해 `extend-select`/`ignore` 로 한 번에 처리할지 결정 필요.
  - `fastapi.testclient.TestClient` 가 내부적으로 `starlette.testclient`(httpx 기반)를 쓰는데 설치된 버전 조합에서 `StarletteDeprecationWarning: Using httpx with starlette.testclient is deprecated; install httpx2 instead` 경고가 발생(테스트는 실패하지 않음, 기능상 문제 없음) — 당장 조치 불필요, 추후 FastAPI/starlette 버전업 시 재확인.
- 교훈:
  - FastAPI 는 동기 `def` 의존성/엔드포인트를 스레드풀에서 실행하므로, 테스트 픽스처 스레드에서 직접 연 `sqlite3.Connection` 을 override 로 주입하면 "스레드가 다르다"는 오류가 실측으로 재현된다 — `check_same_thread=False` 가 없으면 로컬 단일 프로세스 아키텍처(ADR-001)에서도 FastAPI 요청 처리 자체가 깨진다는 점을 처음 구현해보고서야 발견했다(설계 문서만으로는 드러나지 않음).
  - (security 리뷰 FAIL 조치) 클라이언트가 보낸 `UploadFile.filename` 은 신뢰할 수 없는 입력이며 `Path` 결합 전에 반드시 베이스네임만 취해야 한다(CWE-22) — 업로드 파일 저장 경로를 만드는 모든 라우터(이번 `app/api/models.py`, 향후 `app/api/datasets.py` T-011)에 적용해야 할 공통 패턴: `Path(filename or "").name` 으로 정제 → 빈 값/`.`/`..` 는 고정값으로 대체 → `uuid4` 접두어로 충돌 방지 → 최종적으로 `dest.resolve().is_relative_to(target_dir.resolve())` 로 한 번 더 방어적으로 확인. 이 패턴을 `app/eval/` 공용 유틸로 빼서 datasets 라우터(T-011)와 공유할지는 구현 중 판단할 것(현재는 `app/api/models.py` 내부 헬퍼로만 존재).
